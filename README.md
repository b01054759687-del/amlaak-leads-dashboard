## 📊 Overview
Interactive, responsive Executive Leads Dashboard designed for C-Level executives, Marketing Directors, and Sales Managers to analyze, filter, and track lead qualification rates, area sweet spots (150-250m²), expatriate buyers in Saudi Arabia, and sales rep pipeline performance.

## 🎛️ Key Features
- **Mobile & PC 100% Responsive Design:** Touch-friendly controls, responsive charts, and mobile swipeable tables.
- **Interactive Timeline Slider:** Date range scrubber and presets (July, August, Last 7 Days).
- **Dynamic Area Range Slider:** Real-time filter from 50m² to 500m².
- **Live ApexCharts Suite:** Real-time lead flow area chart, qualification donut, sweet-spot area distribution, and geo-demand heatmap.
- **1-Click WhatsApp CRM Table:** Direct chat link for sales follow-up.
- **CSV & Excel Export:** Instant export of filtered datasets.

## 📁 Repository Structure
- `index.html`: The interactive web dashboard application.
- `data.json`: Sanitized and normalized leads dataset.
- `README.md`: Project documentation and user guide.
